# LumeNav · 导航站程序

以光引路，一页直达。纯原生 **PHP + MySQL** 导航站程序，**零框架、零依赖**，自带安装向导、后台管理与主题机制。

> 同族产品：LumeTerm（终端）→ LumeNav（导航）

## 特性

- **一键安装**：浏览器向导建库建表，数据库不存在时自动尝试创建，`config.php` 生成后自动锁定防重装
- **后台管理**：网站设置 / 导航链接增删改 / 主题切换 / 账号设置，全中文界面
- **主题机制**：主题放 `template/<名称>/` 即插即用，后台单选切换，详见 [模板开发文档](template/README.md)
- **图片双通道**：Logo / 背景图支持本地上传或填写外链，可一键清除恢复主题默认
- **多引擎搜索**（极光主题）：百度 / 必应 / 谷歌 / 搜狗 / 360 一键切换
- **大屏自适应 + 手机端**：布局随视口缩放，移动端单列居中
- **安全**：PDO 预处理防注入、CSRF 校验、XSS 输出转义、`password_hash` 存储密码、登录失败随机延迟、Session Cookie HttpOnly + SameSite、上传类型白名单

## 环境要求

| 项 | 要求 |
|---|---|
| PHP | 8.0+（8.5 实测），需 `pdo_mysql`、`mbstring` 扩展 |
| MySQL | 5.7+ / 8.0 / MariaDB（utf8mb4） |
| Web 服务器 | Apache / Nginx 均可，无特殊重写规则 |

## 安装

1. 将程序上传到网站根目录（示例：`C:/lumenav`）
2. 浏览器访问 `http://你的域名/`，会自动跳转到安装向导
3. 填写数据库信息（主机 / 端口 / 库名 / 账号 / 密码）、管理员账号、网站名，点击「开始安装」
4. 安装完成：程序自动建 3 张表（`lumenav_links` / `lumenav_settings` / `lumenav_admin`）、生成 `config.php`、创建 `uploads` 目录
5. **安全建议**：删除根目录下的 `install.php`（已有安装锁，不删也不可重装）

## 目录结构

```
├── index.php          前台入口（主题加载器）
├── admin/
│   └── index.php      后台
├── install.php        安装向导（装完可删）
├── config.php         数据库配置 + 公共函数（安装时自动生成）
├── template/          主题目录
│   ├── default/       默认主题（浅色玻璃态，大屏自适应）
│   ├── aurora/        极光主题（深色极光 + 多引擎搜索）
│   └── README.md      模板开发文档
└── uploads/           上传的图片
```

## 后台功能

入口：`http://你的域名/admin/`

| 模块 | 功能 |
|---|---|
| 网站设置 | 网站名、首页大标题、SEO 关键词/描述、ICP 备案号、版权信息；Logo 与背景图（上传 / 外链 / 清除）；模板主题切换 |
| 导航管理 | 添加、行内编辑、删除链接；排序（小号在前）；新窗口打开开关 |
| 账号设置 | 修改用户名（需验证当前密码）、修改密码（需验证旧密码） |

## 忘记管理员密码？

用任意能连库的方式执行（先生成新哈希；`php` 需已加入 PATH，否则替换为你的 php.exe 完整路径）：

```
php -r "echo password_hash('新密码', PASSWORD_DEFAULT);"
```

```sql
UPDATE lumenav_admin SET password = '上一步输出的哈希' WHERE username = '你的用户名';
```

用户名也可直接查表：`SELECT username FROM lumenav_admin;`

## 修改后台地址

后台入口默认是 `/admin/`。后台「账号设置 → 后台地址」可将目录重命名为任意名称（如 `my-panel`，需验证当前密码），旧地址立即失效，可避开扫描器。页面内链接全部自动跟随，无需改代码。

忘记后台地址时：到 FTP / 文件管理器查看根目录，除 `template`、`uploads` 外的那个子目录就是后台，改回 `admin` 也可以。

## 备份 / 迁移

备份三样即可：`config.php`（数据库配置）、`uploads/`（图片）、数据库导出。换服务器时恢复文件 + 导库，无需重装。
